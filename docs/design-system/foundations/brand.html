Principles

MastersFit is a training companion for masters-age lifters (40+). The visual system is deliberately quiet, achromatic by default, and high-contrast — the product's personality comes from precision and honesty, not decoration. These eight rules are extracted from the design decisions recorded in the codebase (the MF-### series), not invented for this document.

Voice

Plain, concrete, never hype. "End now to save progress and mark the workout as done." — not "Awesome work, champion!" Numbers are stated, not celebrated. The one permitted flourish is the 🔥 streak emoji, which carries the warmth so the palette doesn't have to.
Irreversible actions are spelled out. Destructive paths use the danger token and, where truly unrecoverable, a type-to-confirm gate.

Operating principles

01

Solid ink is rationedMF-006

Exactly one solid filled control per screen: the primary action. Everything informational — muscle groups, equipment, counts, tags — is an outline chip. When data wore ink pills, users tapped them.

02

No status by color aloneMF-005 / MF-011 / MF-019

Every stateful cue carries a second channel. The active tab is a filled glyph vs an outline one, not just a tint. A selected calendar day is a ring, not a fill. A chosen date prints the date. Selection is announced via accessibilityState, never inferred from hue.

03

Elevation goes lighter, both waysMF-010

Light themes step surfaces toward grey; dark themes step them toward white. surface equalled background in every theme, which made every card invisible — card now resolves to neutral.light[2] so a card is always a real tonal step.

04

Built for masters-age eyesMF-008

The type floor is raised across the board: xs 11→13, sm 13→14, base 15→16. There is no 11px body text in this app. 40+ lifters read this mid-set, sweaty, in a gym.

05

44px is the floor, alwaysMF-009 / MF-014

Every tappable thing presents a 44×44 target even when its glyph is 20px. Icon-only controls take a required accessibilityLabel — the component will not compile without one.

06

One control, one placeMF-016 / MF-022

Hand-rolled duplicates of a shared control are how bugs breed: five copies of a segmented row is what let the 6M/1Y filter-vs-label mismatch ship per-card. Shared primitives, fixed once.

07

The current task dominatesMF-012

Once a workout starts, the plan overview collapses to a progress rail and notes hide behind a row. Nothing competes with the set being logged.

08

Admit what a change costsMF-006 / trust

When a swap loses a muscle group, the app shows a dashed grey chip with a minus — never a hidden gap. Covered gets a solid green chip and a check. The app says what it did.
