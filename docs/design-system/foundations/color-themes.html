Theme families

Every screen renders through CSS variables set by NativeWind's vars(), so all ten variants are the same components with a different palette bound. Original is achromatic — near-black ink on white — and the four alternates are low-chroma tints. None is a saturated brand colour; the system leans on contrast and tone, not hue.
